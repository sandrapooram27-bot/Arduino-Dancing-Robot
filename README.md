# Arduino Dancing Robot 🤖

A 4-motor dancing robot built using Arduino and L298N.

## Components
- Arduino Uno
- L298N Motor Driver
- 4 DC Motors
- HC-SR04 Ultrasonic Sensor

## Features
- Forward movement
- Backward movement
- Left and right movement
- 360° rotation
- Random dancing movements

## Motor Pins
- ENA → D5
- IN1 → D8
- IN2 → D9
- IN3 → D10
- IN4 → D11
- ENB → D6
